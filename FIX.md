# Исправление drawer_dock 1.0.1

Проверено на смартфоне OnePlus 7 Pro (GM1910), exteraless, 18 октября 2026 года.

## Причина

SDK exteraless разрешает оба имени `app.exteraless.drawer.DrawerMenuView`
и `com.exteragram.messenger.drawer.DrawerMenuView` в один и тот же Java-класс.
Плагин регистрировал по три обработчика для каждого имени, то есть каждый
метод обрабатывался дважды.

Первый вызов после `rebuildMenu` находил пункты `[14, 102, 106]`, убирал их
из списка и создавал нижнюю строку. Второй вызов уже не находил эти пункты,
заменял `self.moved` пустым списком и удалял только что созданную строку.
Поэтому выбранных пунктов не было ни в списке, ни снизу.

## Изменение

Перед установкой обработчиков добавлена проверка фактического имени класса
через `Class.getName()`. Для одного класса обработчики устанавливаются
один раз. Оба варианта имени остаются для совместимости. Версия — 1.0.1;
идентификатор, настройки и остальные возможности сохранены.

## Проверка

- На устройстве отображаются три кнопки: «Архив чатов», «Плагины», «Лента».
- Нажатие каждой кнопки открывает соответствующий экран.
- Счётчики архива и ленты отображаются.
- После закрытия и открытия меню, перезагрузки плагина и полного перезапуска
  приложения строка сохраняется.
- Файл сохранённых настроек совпадает с исходным побайтово.
- Установленный исходник совпадает с локальным с учётом перевода строк LF/CRLF.
- Проверены синтаксис и регистрация трёх, а не шести обработчиков при двух
  именах одного класса.

Исходная версия сохранена в `backups/drawer_dock.original.plugin`.
Снимки реального экрана находятся в `artifacts/`.
